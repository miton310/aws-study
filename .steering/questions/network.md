# ネットワーク - 問題履歴

## 1. セキュリティグループとNACLの違い（HTTP通信許可）

### テーマ
- パブリックサブネット上のEC2にHTTP(80)でアクセスできるようにする設定
- SGとNACLのステートフル/ステートレスの違い

### 重要ポイント
| 特性 | セキュリティグループ | ネットワークACL |
|------|---------------------|-----------------|
| ステート | ステートフル | ステートレス |
| 戻り通信 | 自動許可 | 明示的に許可必要 |
| 適用対象 | ENI（インスタンス） | サブネット |
| デフォルト | インバウンド全拒否 | 全許可 |

### 正しい設定
- **SGでインバウンド80番を許可するだけでOK**
- SGはステートフルなので、戻り通信は自動許可される
- NACLはデフォルト全許可なので追加設定不要

### よくある誤解
1. NACLで「その他すべて拒否」→ 戻り通信（エフェメラルポート1024-65535）がブロックされる
2. SGでアウトバウンド許可 → インバウンドとアウトバウンドの方向を混同
3. NACLでアウトバウンド許可 → リクエスト（インバウンド）がブロックされる

### 作成した図解
- `src/components/diagrams/SgNaclAnimation.astro`
- 配置: `/network/vpc`

## 2. NAT Gateway経由のインターネットアクセス

### テーマ
- プライベートサブネット上のEC2からインターネット上のWebコンテンツにアクセスしたい
- インターネット接続に失敗する原因

### シナリオ設定
- EC2にプライベートIPアドレスのみ割り当て
- VPCにIGW作成済み
- パブリックサブネットのルートテーブル → IGW 設定済み
- パブリックサブネットにNAT Gateway作成済み
- SG/NACLはデフォルト設定

### 正解
**プライベートサブネットのルートテーブルに、NATゲートウェイへのルーティングが設定されていない**

### 重要ポイント
| 設定項目 | 問題か？ | 理由 |
|---------|---------|------|
| EC2にプライベートIPのみ | ✓ 正常 | NAT経由なのでパブリックIP不要 |
| IGW作成済み | ✓ 正常 | NAT GWがIGWを使う |
| パブリックRT → IGW | ✓ 正常 | NAT GWの外向き通信用 |
| NAT GW作成済み | ✓ 正常 | パブリックサブネットに配置 |
| SG/NACLデフォルト | ✓ 正常 | デフォルトで許可される |
| **プライベートRT → NAT** | **❌ 未設定** | **これが原因！** |

### よくある誤解
1. EC2にパブリックIP不要 → NAT経由の場合は不要
2. NACLの許可 → デフォルトで全許可
3. SGの許可 → アウトバウンドはデフォルト全許可

### 作成した図解
- `src/components/diagrams/NatGatewayAnimation.astro`
- 配置: `/network/vpc`

## 3. ELBのSSL/TLS暗号化（End-to-End暗号化）

### テーマ
- ELB配下に複数台のEC2インスタンスがWebサーバーとして稼働
- クライアントからWebサーバーまで全ての通信を暗号化

### 重要ポイント
| パターン | クライアント→ELB | ELB→EC2 | EC2の証明書 | 用途 |
|---------|-----------------|---------|------------|------|
| SSL終端 | HTTPS | HTTP | 不要 | 一般的なWebアプリ |
| **End-to-End暗号化** | **HTTPS** | **HTTPS** | **必要** | 金融・医療など規制要件 |

### SAA頻出ポイント
- 「クライアントからWebサーバーまで全ての通信を暗号化」→ **End-to-End暗号化**
- ELB→EC2間もHTTPSにするには、EC2に証明書をインストールする必要がある
- ACMの証明書はELBに直接アタッチできるが、EC2にはエクスポートできない
- EC2用の証明書は**ACM Private CA**または自己署名証明書を使用

### 作成した図解
- `src/components/diagrams/ELBDiagram.astro` の「SSL/TLS暗号化」タブ
- 配置: `/compute/ec2` または ELBページ
